Fun facts form: no AI needed

Type each coworker's name and the fun fact they chose to share, written so it follows "Who on our team…" (for example has met a penguin up close). We write the questions, add 3 other names from your list to each one, and print the answer sheets, host cards and answer key. Only use facts people were happy to share.
