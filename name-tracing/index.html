Name Tracing Maker

Type a name, and the tracing pages are ready at once. Print them at home or save them as a PDF.

1 Type the name. Several children? Put one name on each line.
2 Pick the letter size, the dot size and the pages. The preview below changes as you type.
3 Pick US Letter or A4 below, then tap Print / Save as PDF. In the print window choose the same paper, Actual size / 100%, and turn off headers and footers.
🔒 Nothing you type leaves this device: no account, no upload. The form is kept only in this browser, so it is usually still here next time. Clear everything removes it.

Names

Several children or a class? Put each name on its own line, like:
Emma
Liam
First names work best: a long name is printed smaller so it fits on the line.

Pages

To get a PDF file, pick Save as PDF as the printer. Phone: in the print window, iPhone: Share → Save to Files; Android: choose Save as PDF as the printer. Print at Actual size / 100% on the paper you picked above.
For your own family and your own classroom: print as many copies as you need. Please don't resell or share the Maker or the pages.
